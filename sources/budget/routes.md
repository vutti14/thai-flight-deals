# Budget-airline (LCC) nonstop route matrix from Bangkok (Oct 2026 – Apr 2027)

Built 2026-10-11 (Asia/Bangkok). Nonstop from DMK or BKK only. Thai domestic excluded. Times local; schedule tables are Oct 2026 (pre-winter) unless a note gives winter times; frequencies estimated from 2LNR next-7-service-days table.

**Google Flights coverage:** Google Flights shows Thai AirAsia / AirAsia X schedules but 'Total price is unavailable' (no fares) in our checks; Thai Vietjet/VietJet are priced; Thai Lion Air appears only on some routes (e.g. HGH priced) and is missing on others (e.g. PVG). A fare sweep via Google Flights therefore covers VZ/VJ (+ some SL) prices; FD/XJ/SL fares need airasia.com / lionairthai.com (or an OTA) for exact prices.

Status: `operating` = in current schedule; `resumes` = resumes on start date; `seasonal` = winter-seasonal; `suspended` = currently suspended; tentative restart on start date; `tentative` = filed but not bookable yet; `charter` = scheduled charter / charter-type flight numbers (often sold via tour agents); `ended` = ends before window; `not_nonstop` = same-plane via another city; `not_operating` = listed somewhere but no flights scheduled; `not_in_schedule` = listed by 2LNR, no flights in next 7 service days
