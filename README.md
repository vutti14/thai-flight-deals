# thai-flight-deals

แดชบอร์ดตั๋วการบินไทยชั้นประหยัดราคาดี จากกรุงเทพฯ (BKK) — เอเชีย (อินเดีย จีน เวียดนาม พม่า) และยุโรป (ปารีส อัมสเตอร์ดัม ซูริก มิลาน)

Thai Airways economy flight-deal dashboard from Bangkok. Static site (GitHub Pages).

- `index.html` — dashboard (calendar, list sorted by date, route × month table, compare search runs)
- `snapshots.js` — all search results (one entry per search run); generated by `build.py` in the private workspace

Prices: THB, round trip, 1 adult, economy, nonstop TG, from Google Flights. Prices change — always re-check before booking.
