# thai-flight-deals

แดชบอร์ดตั๋วการบินไทยชั้นประหยัดราคาดี จากกรุงเทพฯ (BKK) — เอเชีย (อินเดีย จีน เวียดนาม พม่า) และยุโรป (ปารีส อัมสเตอร์ดัม ซูริก มิลาน)

Thai Airways economy flight-deal dashboard from Bangkok. Static site (GitHub Pages).

- `index.html` — dashboard with an Economy / Business switch (`#class=business`) (calendar, list sorted by date, route × month table, compare search runs)
- `snapshots.js` — all search results (one entry per search run); generated by `build.py` in the private workspace

Coverage: Oct 2026 – Apr 2027 (incl. Songkran). Routes: India, China, Hong Kong, Vietnam, Myanmar, Japan (Osaka, Nagoya, Tokyo NRT/HND, Fukuoka), Europe (Paris, Amsterdam, Zurich, Milan). Prices: THB, round trip, 1 adult, economy or business, TG, from Google Flights; `~` = approximate calendar price. Prices change — always re-check before booking.
