# thai-flight-deals

แดชบอร์ดตั๋วการบินไทยชั้นประหยัดราคาดี จากกรุงเทพฯ (BKK) — เอเชีย (อินเดีย จีน เวียดนาม พม่า) และยุโรป (ปารีส อัมสเตอร์ดัม ซูริก มิลาน)

Thai Airways economy flight-deal dashboard from Bangkok. Static site (GitHub Pages).

- `index.html` — dashboard with an Economy / Business switch (`#class=business`) (calendar, list sorted by date, route × month table, compare search runs)
- `snapshots.js` — all search results (one entry per search run); generated by `build.py` in the private workspace

Coverage: Oct 2026 – Apr 2027 (incl. Songkran). Routes: India, China, Hong Kong, Vietnam, Myanmar, Japan (Osaka, Nagoya, Tokyo NRT/HND, Fukuoka), Europe (Paris, Amsterdam, Zurich, Milan). Prices: THB, round trip, 1 adult, economy or business, TG, from Google Flights; `~` = approximate calendar price. Prices change — always re-check before booking.

## Trip.Best 100 (`best100/`, added 19 Nov 2026)
Hotels and attractions from Trip.com **Trip.Best 2027** (Global 100 / Asia 100: luxury, scenic, cultural hotels; things to do, family, night) plus each city's Trip.Best Top list (China/GBA, Singapore, Tokyo, Dubai), filtered to destinations with a **nonstop flight from Bangkok (BKK/DMK)** verified on Google Flights (sample dates 20 + 23 Jan 2027). Every name, rank and link comes from the Trip.com pages. Build sources: `sources/best100/` (`extract_lists.py` → `build_best100.py`).

**Update 20 Nov 2026.** Added Hainan (Haikou, Sanya) and Shandong (Qingdao) groups inside China, included on request for work trips even without a nonstop. Direct check: BKK/DMK/HKT/CNX on 5 dates Dec 2026–Mar 2027 (`raw/direct-hainan-tao.json`). Sanya has no nonstop, so the page shows the best 1-stop routings instead (`onestop_sweep.py` → `raw/onestop-SYX.json`). Each city also gets a 💼 box of hotels whose Trip.com location tag sits near the convention centre, CBD, railway station or airport. Added an India section covering every city Thai Airways flies nonstop from BKK in winter 2026/27 (DEL, BOM, CCU, MAA, BLR, HYD, AMD, GAY), using each city's Trip.Best Premium/Luxury list filtered to 5-star brands (`raw/direct-india.json`). The city-list cache now lives in `best100/cache/` and `extract_lists.py` merges into the stored json.
